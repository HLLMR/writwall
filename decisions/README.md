# Methodology decisions

This log records ratified changes to the Doctrine itself under Doctrine DC.3.4. Project-level decisions never live here.

`DR-001` ratified Doctrine revision 0.6 on 2026-08-16. It is the first ratified decision of this repository and the first authoritative revision of the methodology; revisions 0.1 through 0.5 were never ratified.

DR-002 is intentionally unused in the methodology series. The completed
ten-work-order pilot was dispositioned by the private governed source's
project decision `governance/decisions/DR-002.md`; that record is not a
methodology decision and is not carried by public candidates.

`DR-003` recorded HLLMR Ventures LLC's copyright ownership and ratified the
the project's license map on 2026-08-20. It resolves RFI-03.

`DR-004` ratified Doctrine revision 0.7 on 2026-08-20, superseding 0.6.

`DR-005` ratified Doctrine revision 0.8 on 2026-08-21, superseding 0.7.
`DR-006` ratified Doctrine revision 0.9 on 2026-09-16, superseding 0.8.
Revision 0.9 is the current ratified methodology revision (`DOCTRINE.md`
DC.1). Projects already bound to earlier revisions, including this repository's
own project-side governance instance bound to 0.8, remain bound to their recorded
revision until their Owner separately ratifies migration (DC.4); see
`migration-guides/0.6-to-0.7.md` and `migration-guides/0.7-to-0.8.md`.

`LICENSING-DIRECTION.md` is preserved superseded direction, not a decision
record. Files in this directory carry authority only when they are numbered
`DR-nnn` and ratified by the Owner.

These are the **methodology's** decisions. This repository's own project-side decisions, once it self-adopts, will live in `governance/decisions/` and are a separate series (Doctrine 5.1.5).
